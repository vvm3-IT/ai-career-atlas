# Compare career paths

Use this as a starting point for reading job descriptions. Team scope and seniority can change the balance substantially.

| Role family | Primary focus | Strong evidence of ability |
| --- | --- | --- |
| [Forward Deployed Engineer](/roles/forward-deployed-engineer) | Customer delivery | Interview a user, map a workflow, deploy an assistant with human review, and document the measured outcome. |
| [AI / Applied AI Engineer](/roles/ai-engineer) | Product engineering | Build a source-citing research assistant with a labeled test set, failure analysis, latency measurements, and a cost budget. |
| [Applied AI Architect](/roles/applied-ai-architect) | Technical advisory | Write an architecture decision record and build a small proof of concept with a rollout and evaluation plan. |
| [AI Evaluation Engineer](/roles/evaluation-engineer) | Quality & measurement | Compare two assistant versions on a versioned dataset; report quality, uncertainty, cost, and failure regressions. |
| [Research Engineer](/roles/research-engineer) | Research & experimentation | Reproduce a small published result with a baseline, ablations, tracked configuration, and an honest limitations section. |
| [Inference / ML Systems Engineer](/roles/inference-engineer) | Infrastructure | Benchmark a model-serving workload across batch sizes and concurrency, reporting throughput, tail latency, and hardware. |
| [AI Security / Safeguards Engineer](/roles/ai-security-engineer) | Security & reliability | Threat-model a tool-using assistant and demonstrate tests for prompt injection, data access boundaries, and safe tool execution. |

## Pick a direction

- Enjoy customer discovery and shipping under ambiguity? Explore **forward deployed engineering**.
- Want to build AI features in a product? Explore **AI engineering**.
- Prefer architecture and technical explanation? Explore **applied AI architecture**.
- Enjoy measurement and finding failures? Explore **evaluation**.
- Want to run experiments on model behavior? Explore **research engineering**.
- Prefer performance and systems? Explore **inference engineering**.
- Enjoy adversarial thinking? Explore **AI security**.

These are orientation prompts, not an assessment of your suitability. Try a small project before committing to a path.
