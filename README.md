# AI Career Atlas

A VitePress research site about emerging AI career paths: forward deployed engineers, AI engineers, applied AI architects, evaluation, research, inference, and AI security.

**Website: [AI Career Atlas on GitHub Pages](https://vvm3-it.github.io/ai-career-atlas/)**

## What’s inside

- Seven role field guides with responsibilities, skills, portfolio projects, and employer questions
- Side-by-side career comparison and an eight-week project roadmap
- Primary-source register and a clear distinction between evidence and editorial synthesis
- Local search, mobile navigation, and light/dark themes

## Develop locally

Requires Node.js 22 or newer.

```sh
npm ci
npm run docs:dev
```

```sh
npm run docs:build
npm run docs:preview
```

## GitHub Pages

The deployment workflow builds VitePress on pushes to `main` and publishes `docs/.vitepress/dist` using GitHub Actions. In repository **Settings → Pages**, select **GitHub Actions** as the source. The VitePress base path is `/ai-career-atlas/`.

## Research

Research reviewed November 5, 2026. This is a curated guide, not a live job board. See [sources and methodology](docs/research.md). Career guidance and portfolio ideas are editorial synthesis; job titles and openings change.
